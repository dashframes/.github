### What we make

| | |
|---|---|
| 🎬 **Launch films** | Make people want the product. Built for launch day — homepages, launches, social posts, ads and pitch decks. |
| 🧭 **How-to videos** | Show people how to use it. Clear, on-brand walkthroughs that stay current as the product changes. |

**1–3 min** per video · **days, not weeks** turnaround · **100%** of the video, source and brand files are yours.

### How it works

```
Connect  →  Script  →  Storyboard  →  Render
free call   you approve  you approve    delivered on GitHub
```

1. **Connect** — a free call about your product and audience; you hand over brand assets.
2. **Script** — drafted from the call, one round of feedback, you approve.
3. **Storyboard** — every scene sketched and timed with the voice, you approve.
4. **Render** — rendered in HyperFrames and shared as a private GitHub repo with the final video and every file.

### Yours to keep

Most studios hand over an MP4 and keep the files. You get the film **and everything it's made from**:

- 🗂️ **Full source** — `index.html`, assets, voice, music, in a private repo you own.
- 🤖 **Claude Code skills & plugins** — `/brief` `/script` `/storyboard` `/render` `/variants`, so you can keep producing the way we do.
- 🎨 **Your brand, written down** — `design.md` and `motion.md` keep every future video on-brand.
- 📐 **One video, every format** — ask Claude Code for 9:16, 1:1, 4K, short clips and carousels. No new invoice.
